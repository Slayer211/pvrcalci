Movie Deal Calculator
======================
1. Extract the ZIP.
2. Open index.html in a browser to use it.
3. To put it online, upload index.html and manifest.json to any static web host.
4. On a phone, open the hosted page and use "Add to Home Screen" in the browser.

The calculator includes:
- + / - ticket controls
- Ticket price
- Convenience fee per ticket
- No Offer / B1G1 / B2G1
- GV percentage discount
- Automatic final amount
